# Deutsch Wörter

A small static page for practising German words day by day, color-coded by article (der / die / das / plural).

**Live site:** https://cmajid.github.io/german/

Every push to `main` is published automatically by GitHub Pages, which deploys straight from the `main` branch.

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.
